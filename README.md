# ⚽ World Cup 2026 Telegram Bot

ربات گزارش زنده بازی‌های جام جهانی برای کانال تلگرام — دوزبانه فارسی/انگلیسی

---

## فایل‌ها

| فایل | کار |
|------|-----|
| `bot.py` | نقطه شروع — ربات رو راه‌اندازی می‌کنه |
| `monitor.py` | هر ۶۰ ثانیه API رو چک می‌کنه، رویدادها رو تشخیص میده |
| `formatter.py` | پیام‌های فارسی/انگلیسی رو می‌سازه |
| `requirements.txt` | کتابخونه‌های مورد نیاز |
| `Procfile` | تنظیم Railway |

---

## متغیرهای محیطی (Environment Variables)

در Railway باید این ۳ تا رو تنظیم کنی:

```
BOT_TOKEN     = توکن ربات از BotFather
CHANNEL_ID    = آیدی کانال مثلاً @worldcup2026fa یا -1001234567890
FD_API_KEY    = کلید API از football-data.org
```

---

## راه‌اندازی روی Railway

1. یه پروژه جدید بساز در Railway
2. گزینه "Deploy from GitHub repo" رو انتخاب کن
3. یا فایل‌ها رو مستقیم آپلود کن
4. Environment Variables رو اضافه کن (بالا)
5. Railway خودکار با `Procfile` اجرا می‌کنه

---

## گرفتن API Key رایگان

1. برو به: https://www.football-data.org/client/register
2. ثبت‌نام کن (رایگانه)
3. API Key رو از داشبورد بگیر
4. پلن رایگان: ۱۰ درخواست در دقیقه — کافیه ✅

---

## رویدادهایی که ربات گزارش میده

- 🟢 شروع بازی
- ⚽ گل (با نام گلزن + دقیقه)
- 🎯 پنالتی
- 🥅 گل به خودی
- ⏸ پایان نیمه اول
- 🔴 پایان بازی + نتیجه نهایی

## نکته مهم

football-data.org در پلن رایگان **کارت زرد/قرمز** رو در live data نمیده.
اگه بخوای اونارو هم داشته باشی باید پلن پولی بگیری یا از API دیگه‌ای استفاده کنی.
